Introducción: Se analizó una conexión HTTP utilizando las herramientas de desarrollador de Chrome.

Sitio analizado: http://neverssl.com

Evidencia observada: Se identificaron el método GET, Host, URL, puerto 80 y distintos Headers.

Riesgos encontrados: HTTP no cifra la comunicación, por lo que los datos pueden quedar expuestos o ser interceptados.

VPN: Crea un túnel cifrado que protege el tráfico entre el dispositivo y el servidor VPN.

Mis 3 Reglas de Oro:

Evitar ingresar datos sensibles en páginas HTTP.

Utilizar una VPN en redes Wi-Fi públicas.

Conectarse a redes confiables y mantener los dispositivos actualizados.
